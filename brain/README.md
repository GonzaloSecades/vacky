# Vacky brain

The brain stores current facts, decisions, and evidence that code alone cannot explain.

Start with [current state](wiki/now.md). Read only the pages relevant to the task.

- [Architecture](wiki/architecture/overview.md): what runs today.
- [Data and auth](wiki/architecture/data-and-auth.md): persistence and trust boundaries.
- [Product direction](wiki/product/direction.md): accepted direction and deferred scope.
- [Risks](wiki/risks.md): known problems and missing verification.
- [Decisions](wiki/decisions/README.md): choices and their reasons.
- [Backend plan](../docs/nestjs-backend.md): the only active implementation checklist.

Update the smallest affected page when a durable fact changes.
Record important decisions with their reasons and accepted costs.
Keep raw evidence only when future work needs it.
Do not create session notes, extra plans, or PR summaries by default.

`raw/` preserves historical evidence. `outputs/` holds supporting drafts and ideas.
Neither folder overrides the current wiki or the user's latest instructions.
The retired Operator workflows and Vacky automation skills are under [deprecated material](../deprecated/README.md).
Graphify is optional navigation. It is not required for development or brain updates.
The project brain is separate from the product's traveler profile and recommendation data.
