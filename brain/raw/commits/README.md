# Commit Sources

Store meaningful commit summaries here when a plain git log is not enough.

Each file should answer:

- what changed
- why it changed
- what risk it introduced
- what should be reflected in the wiki

This folder can also hold PR or merge snapshots when review iterations changed the final branch in ways that are worth preserving.
