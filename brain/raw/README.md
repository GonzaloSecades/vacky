# Raw Sources

`raw/` stores source material before it is compiled into the wiki.

Treat these files as evidence, not polished documentation.

## What Belongs Here

- session notes
- pasted chat excerpts
- commit snapshots
- repo observations
- screenshots
- copied issue text
- external references tied to Vacky

## Conventions

- Prefer dated filenames: `YYYY-MM-DD-short-name.md`
- Keep one topic per file where possible
- Do not over-edit old raw notes; add a new file instead
- If a source is incomplete or uncertain, say so directly

## Suggested Subfolders

- `sessions/`: coding-session notes and summaries
- `commits/`: meaningful commit or diff snapshots
- `references/`: external docs or research relevant to Vacky
- `verification/`: command, browser, accessibility, and manual-check evidence

The wiki should summarize and connect this material. It should not replace it.
