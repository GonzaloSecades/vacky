# PR Prep Sync Template

```text
Before I open or update a PR for this branch, inspect the diff against `master` and sync the Vacky brain.

Read:
- `brain/wiki/now.md`
- `brain/wiki/index.md`
- `brain/wiki/log.md`
- the wiki pages most relevant to this branch

Then:
1. Inspect the branch diff against `master`.
2. Update only the brain pages materially affected by this branch.
3. Append a concise dated note to `brain/wiki/log.md`.
4. Refresh `brain/wiki/now.md` if current state, risks, or next actions changed.
5. If useful, write a reusable brief under `brain/outputs/briefs/`.

Rules:
- Keep the update proportional to the branch.
- Prefer editing existing pages over creating duplicates.
- Preserve uncertainty when the diff does not fully explain intent.
- If a raw session or commit note is needed for provenance, add it under `brain/raw/`.
```
