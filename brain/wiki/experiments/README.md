# Experiments

Store notes about attempts, prototypes, failures, and open explorations.

This folder matters because failed paths are part of the project memory. If they are not recorded, the same mistakes get repeated.

## Historical and deferred experiments

- [Memory-First Direction](../../../deprecated/2026-11-19/brain/wiki/experiments/2026-04-12-memory-first-direction.md): historical product exploration. Current recommendation direction is recorded in the product wiki.
- [DesignRefactor UI Experiment](../../../deprecated/2026-11-19/brain/wiki/experiments/2026-04-21-design-refactor-ui-experiment.md): scoped visual-system experiment across the main travel-facing surfaces.
- [Image Storage And Delivery Optimization](../../../deprecated/2026-11-19/brain/wiki/experiments/2026-10-02-image-storage-and-delivery-optimization.md): proposed cover-image optimization flow using SpacetimeDB metadata/tiny previews, external image variants, authenticated subscriptions, and measured rendering improvements; not implemented or benchmarked. Its SpacetimeDB-specific design is historical.

Each experiment note should capture:

- goal
- method
- outcome
- lesson
- whether it should be retried later
