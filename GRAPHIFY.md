# Optional graph navigation

Graphify is optional. It is not a development prerequisite or a required brain maintenance step.
Code and current wiki pages remain the sources for implementation claims.
Do not recommend a graph refresh after routine changes.

If the user asks for graph work, check the installed tool's help and choose a focused corpus.
Exclude `deprecated/`, generated output, vendored reference packs, dependencies, and local experiments unless explicitly needed.
Treat generated relationships as leads and inspect the source before making implementation claims.

Generated `graphify-out/` files are ignored.
The former generated snapshot remains locally under `deprecated/graphify-snapshot/`.
It is not part of a fresh checkout. Git commit `179df2f8e2f083e7b9a54cb436ac6e263a6eeb42` retains the previous tracked snapshot.
